# MT7927 (Filogic 380 / MT6639) support: experimental, untested on hardware

The MT7927 runs the same firmware interface as the MT7925, so the scan, join, WPA2 and data-path code are shared. The
host-side bring-up is different. That part is ported from upstream mt76 (openwrt/mt76, where MT7927 support was merged
in 2026) and lives in `kexts/itlmt7925/itlmt7927.cpp`:

| What | MT7925 | MT7927 (this port) |
|---|---|---|
| PCI ids | `14c3:7925` | `14c3:7927`, `14c3:6639`, `14c3:0738` |
| Firmware | `mediatek/mt7925/*_1_1*` | `mediatek/mt7927/WIFI_MT6639_PATCH_MCU_2_1_hdr.bin`, `WIFI_RAM_CODE_MT6639_2_1.bin` |
| WFSYS reset | `0x7c000140` RST_B | CBInfra RGU `0x1f8600`, MCU own `0x1f5034`, ROM code idle `0xc1604 == 0x1d1e` |
| RX rings | event 0, data 2 | event 6, data 4, plus ring 7 (second MCU ring) |
| WFDMA | prefetch table A | prefetch CFG0-3 + rings 4/6/7, GLO_CFG ADDR_EXT_EN + FW_DWLD_BYPASS_DMASHDL |
| ASPM | left on | L0s/L1 off on the card and its upstream port |
| After firmware | | UNI `SET_DBDC_PARMS` (DBDC on) |
| band_idx | `0xff` (auto) | 0 on 2.4 GHz, 1 on 5 GHz; the interface is re-added on a band change |

Nothing in that file runs on an MT7925.

## Build (on the Mac, Command Line Tools are enough)

```bash
scripts/fetch-mt7927-fw.sh                  # firmware from linux-firmware into fw/ (not stored in the repo)
scripts/build.sh itlmt7925 itlmt7925Native  # build/itlmt7925.kext, build/itlmt7925Native.kext
```

The build prints `MT7927 firmware found in fw/: embedding it`. Without the firmware the kext still builds, but it refuses
to start on an MT7927.

## Test

Follow [GUIDE.md](GUIDE.md) for installing the kexts and the boot-args, and keep a working EFI on a USB stick to fall back on.
After booting, read the log:

```bash
ioreg -rc itlmt7925 -d1 -w0 | grep -E '"(m1|m2|m3)-log"|wifi-state'
```

What to look for, in order:

1. `pci=6639 (MT7927)` and `aspm off`: the card was recognised.
2. `mt7927 probe own ok`, then `mt7927 sema ...` twice with no `wfsys reset timeout`: the reset worked.
3. `stage 7: patch rc=0`, `stage 8: ram rc=0`, `stage 9: FIRMWARE READY`: the firmware runs. If it stops before this, the
   log line it stopped on is what matters.
4. `mt7927 dbdc=1 rc=0`, `dev_info active=1 band=0 rc=0`, then a scan with networks in it.
5. When joining: `mt7927 band 0 -> 1` (5 GHz) and `roc event ... status=0`.

Known gaps: everything the MT7925 build lacks (WPA3, 6 GHz, AirDrop, sleep), and Wi-Fi 7 / 320 MHz is not used.
